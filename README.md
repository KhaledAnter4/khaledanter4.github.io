## Approach

I approach software quality from three perspectives:

**Functional**

Does the application behave according to its requirements?

**Technical**

Does the application handle data, APIs, workflows, and edge cases correctly?

**Security**

Can the application's logic or controls be abused in unexpected ways?

Combining these perspectives helps me identify defects that may be missed through basic happy-path testing alone.
